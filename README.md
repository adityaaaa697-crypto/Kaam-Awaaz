# Kaam Awaaz (prototype)
Voice-first job alerts and escrow payments for Delhi's daily-wage labourers. Built with AI for a university assignment.

**Everything is simulated:** payments, wallet, OTP, alert calls, and the 18 seeded workers. No real money or personal data.

Try it: tap "I need work", sign in as worker `9000000001` with OTP `1234`; or tap "I need a worker" to post a job.
Voice needs Chrome, Edge or Safari over HTTPS. The Dashboard has a "Reset demo" button.

Run locally: `python3 server.py` then open http://localhost:3456 (set PORT to change the port).
